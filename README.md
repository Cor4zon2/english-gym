# English Gym 🏋️

Веб-приложение для изучения английских слов по методу интервальных повторений (spaced repetition), вдохновлённое [Anki](https://apps.ankiweb.net/).

Идея простая: каждое слово — это карточка. Приложение показывает карточку именно в тот момент, когда вы вот-вот её забудете. Чем лучше вы помните слово, тем реже оно попадается.

> **Статус:** реализован MVP (v0.1) — колоды, редактор карточек, повторение по SM-2, озвучка, статистика, импорт/экспорт CSV и JSON, стартовая колода. Запуск — см. [Быстрый старт](#быстрый-старт).

## Возможности

### MVP (версия 0.1)

- **Колоды** — создание, переименование и удаление колод (например, «IELTS», «Phrasal verbs», «Работа»).
- **Карточки** — добавление и редактирование слов: слово, транскрипция, перевод, определение на английском, примеры, коллокации.
- **Повторение** — сессия в стиле Anki: вопрос → «Показать ответ» → оценка `Again / Hard / Good / Easy`.
- **Интервальные повторения** — алгоритм SM-2 (как в классическом Anki) с очередями новых, изучаемых и повторяемых карточек.
- **Дневные лимиты** — настраиваемое количество новых карточек и повторений в день для каждой колоды.
- **Произношение** — озвучка слова и примеров через встроенный в браузер Web Speech API (британский / американский акцент).
- **Статистика** — карточек к повторению сегодня, серия дней подряд (streak), прогноз нагрузки на неделю, активность за 30 дней, удержание.
- **Работа офлайн** — все данные хранятся локально в браузере (IndexedDB), регистрация не нужна.
- **Импорт / экспорт** — CSV и JSON для резервных копий и переноса между устройствами.
- **Тёмная тема** и адаптивная вёрстка для телефона.

### Дальше (см. [дорожную карту](#дорожная-карта))

- Обратные карточки (перевод → слово) и режим ввода ответа с клавиатуры.
- Импорт колод Anki (`.apkg`).
- Алгоритм FSRS как альтернатива SM-2.
- Синхронизация между устройствами через аккаунт.
- PWA: установка на телефон, уведомления о повторениях.

## Как устроена карточка

Одна карточка тренирует сразу три навыка: **значение**, **сочетаемость** и **употребление** слова.

**Лицевая сторона (вопрос):**

```
┌───────────────────────────────┐
│          meticulous           │
│         /məˈtɪkjələs/  🔊     │
│                               │
│   "She kept ___ records of    │
│    every transaction."        │
└───────────────────────────────┘
```

**Оборотная сторона (ответ):**

```
┌───────────────────────────────┐
│  meticulous  (adj.)           │
│  🇷🇺 дотошный, скрупулёзный     │
│                               │
│  Definition: showing great    │
│  attention to detail          │
│                               │
│  Collocations:                │
│   • meticulous attention      │
│   • meticulous planning       │
│                               │
│  Examples:                    │
│   • She kept meticulous       │
│     records of every          │
│     transaction.              │
└───────────────────────────────┘
   [Again] [Hard] [Good] [Easy]
     <1м     6м    10м    4д
```

Под каждой кнопкой показывается, через сколько времени карточка вернётся при этой оценке — как в Anki.

| Поле            | Обязательное | Пример                                   |
|-----------------|:------------:|------------------------------------------|
| `word`          | да           | `meticulous`                             |
| `translation`   | да           | `дотошный, скрупулёзный`                 |
| `partOfSpeech`  | нет          | `adj.`                                   |
| `transcription` | нет          | `/məˈtɪkjələs/`                          |
| `definition`    | нет          | `showing great attention to detail`      |
| `examples`      | нет          | список предложений                       |
| `collocations`  | нет          | `meticulous attention`, `… planning`     |
| `tags`          | нет          | `ielts`, `b2`                            |
| `notes`         | нет          | произвольная заметка                     |

## Алгоритм повторений

В основе — **SM-2** в варианте Anki.

### Состояния карточки

```
 new ──► learning ──► review ──► (ошибка) ──► relearning ──► review
```

| Состояние    | Что происходит                                                         |
|--------------|------------------------------------------------------------------------|
| `new`        | Карточка ещё ни разу не показывалась.                                  |
| `learning`   | Короткие шаги в рамках дня (по умолчанию `1м → 10м`).                  |
| `review`     | Карточка выучена, интервал измеряется в днях.                          |
| `relearning` | Карточку забыли (`Again`), она снова проходит короткие шаги.           |

### Оценки

| Кнопка   | Клавиша | Эффект в состоянии `review`                                          |
|----------|:-------:|----------------------------------------------------------------------|
| Again    | `1`     | Ease −20%, карточка уходит в `relearning`, интервал сбрасывается.    |
| Hard     | `2`     | Ease −15%, интервал × 1.2.                                           |
| Good     | `3`     | Интервал × ease.                                                     |
| Easy     | `4`     | Ease +15%, интервал × ease × 1.3.                                    |

- Начальный коэффициент лёгкости (ease) — **250%**, минимальный — **130%**.
- Первый интервал после выпуска из `learning` — **1 день** (`Good`) или **4 дня** (`Easy`).
- К интервалам добавляется небольшой случайный разброс (fuzz), чтобы карточки, выученные в один день, не скапливались в один день повторения.
- Все параметры можно менять в настройках колоды.

Алгоритм вынесен в отдельный модуль без зависимостей от UI (`src/srs/`) и покрыт юнит-тестами — это позволит позже подключить FSRS, не трогая интерфейс.

## Сценарий занятия

1. Открываете приложение → видите список колод и число карточек к повторению в каждой: **New / Learn / Due**.
2. Выбираете колоду → начинается сессия.
3. Видите слово, вспоминаете значение и пример употребления (можно проговорить вслух).
4. Нажимаете **«Показать ответ»** (`Space`) и честно оцениваете себя.
5. Когда карточки на сегодня закончились — экран итогов: сколько карточек пройдено, процент правильных ответов, время занятия.

## Технологии

| Слой            | Выбор                                   | Почему                                                      |
|-----------------|-----------------------------------------|-------------------------------------------------------------|
| Язык            | TypeScript                              | Типобезопасная модель данных и алгоритма.                   |
| UI              | React 18                                | Компонентный подход, большая экосистема.                    |
| Сборка          | Vite                                    | Быстрый dev-сервер, простая настройка.                      |
| Стили           | CSS Modules + CSS-переменные            | Без лишних зависимостей, простая тёмная тема.               |
| Хранилище       | IndexedDB через [Dexie](https://dexie.org/) | Тысячи карточек, индексы по дате повторения, работа офлайн. |
| Роутинг         | React Router (`HashRouter`)             | Страницы: колоды, повторение, редактор, статистика. Hash-роутинг работает на GitHub Pages без настройки сервера. |
| Озвучка         | Web Speech API (`speechSynthesis`)      | Встроено в браузер, бесплатно.                              |
| Тесты           | Vitest + Testing Library                | Нативная интеграция с Vite.                                 |
| Линтинг         | ESLint + Prettier                       | Единый стиль кода.                                          |
| Деплой          | GitHub Pages                            | Статический сайт, бэкенд не нужен.                          |

## Модель данных

```ts
interface Deck {
  id: string;
  name: string;
  description?: string;
  settings: DeckSettings;
  createdAt: number;
}

interface DeckSettings {
  newPerDay: number;          // по умолчанию 20
  reviewsPerDay: number;      // по умолчанию 200
  learningSteps: number[];    // в минутах, по умолчанию [1, 10]
  relearningSteps: number[];  // в минутах, по умолчанию [10]
  graduatingInterval: number; // дни, по умолчанию 1
  easyInterval: number;       // дни, по умолчанию 4
  startingEase: number;       // по умолчанию 2.5
}

interface Card {
  id: string;
  deckId: string;
  // содержимое
  word: string;
  translation: string;
  partOfSpeech?: string;
  transcription?: string;
  definition?: string;
  examples: string[];
  collocations: string[];
  tags: string[];
  notes?: string;
  // состояние планировщика
  state: 'new' | 'learning' | 'review' | 'relearning';
  due: number;        // timestamp следующего показа
  interval: number;   // текущий интервал в днях
  ease: number;       // коэффициент лёгкости
  step: number;       // номер шага в learning / relearning
  reps: number;       // всего повторений
  lapses: number;     // сколько раз забыта
  createdAt: number;
  updatedAt: number;
}

interface ReviewLog {
  id: string;
  cardId: string;
  rating: 1 | 2 | 3 | 4;  // Again / Hard / Good / Easy
  stateBefore: Card['state'];
  intervalBefore: number;
  intervalAfter: number;
  easeAfter: number;
  durationMs: number;     // сколько думали над карточкой
  reviewedAt: number;
}
```

`ReviewLog` хранится отдельно: по нему строится статистика, и он пригодится для обучения параметров FSRS в будущем.

## Быстрый старт

Требования: **Node.js 20+** и **npm**.

```bash
git clone https://github.com/cor4zon2/english-gym.git
```

```bash
cd english-gym
```

```bash
npm install
```

```bash
npm run dev
```

Приложение откроется на `http://localhost:5173`. На пустом экране нажмите «Добавить стартовую колоду», чтобы сразу начать.

| Команда           | Описание                                  |
|-------------------|-------------------------------------------|
| `npm run dev`     | Dev-сервер с горячей перезагрузкой        |
| `npm run build`   | Production-сборка в `dist/`               |
| `npm run preview` | Локальный просмотр production-сборки      |
| `npm test`        | Юнит-тесты (Vitest)                       |
| `npm run lint`    | Проверка ESLint                           |

---

### Деплой

Workflow `.github/workflows/deploy.yml` при пуше в `main` прогоняет линт, тесты и сборку и публикует `dist/` на GitHub Pages. Один раз включите в настройках репозитория: **Settings → Pages → Source: GitHub Actions**.

## Импорт и экспорт

### CSV

Первая строка — заголовки. Обязательны только `word` и `translation`. Несколько примеров или коллокаций разделяются символом `|`.

```csv
word,translation,partOfSpeech,transcription,definition,examples,collocations,tags
meticulous,"дотошный, скрупулёзный",adj.,/məˈtɪkjələs/,showing great attention to detail,She kept meticulous records.|He is meticulous about his work.,meticulous attention|meticulous planning,ielts b2
```

### JSON

Полный бэкап (колоды, карточки с прогрессом и история повторений) — для переноса на другое устройство.

## Горячие клавиши

| Клавиша     | Действие                  |
|-------------|---------------------------|
| `Space`     | Показать ответ / «Good»   |
| `1`–`4`     | Again / Hard / Good / Easy |
| `P`         | Произнести слово          |
| `E`         | Редактировать карточку    |
| `Ctrl+Z`    | Отменить последнюю оценку |

Клавиши `1`–`4` работают, когда ответ открыт. `Enter` дублирует `Space`.
